Ingesta y procesamiento

Self-Hosted Integration Runtime + Data Factory

Agente on-premises que extrae pólizas, siniestros y reservas del core con solo tráfico saliente HTTPS. ADF orquesta la extracción diaria; Blob Storage aterriza los datos crudos y procesados.

Validación

Azure Functions — Validación XSD

Valida el XML generado contra el esquema exigido por la SMV antes de continuar el flujo, evitando rechazos por formato.

Orquestación y envío

Logic Apps + SQL DB + Durable Functions + RPA

Logic Apps coordina el flujo diario; SQL Database mantiene el calendario regulatorio; Durable Functions reintenta ante fallas transitorias; Power Automate Desktop automatiza la carga en el portal web de la SMV (sin API/SFTP).

Evidencia y monitoreo

Blob WORM + Power BI + Alertas

Constancias inmutables con retención de 365 días (lifecycle Hot → Cool → Archive). Power BI expone el dashboard de cumplimiento; Teams/Email alertan ante riesgo de incumplimiento del plazo diario.

Guía técnica para implementación en Azure

Servicios, SKU recomendado y consideraciones de seguridad/red para llevar esta arquitectura a producción.

CapaServicio AzureSKU / Tier sugeridoConsideraciones clave
Ingesta Self-Hosted Integration Runtime + Azure Data Factory ADF: Standard, trigger Tumbling Window diario SHIR en servidor on-prem con solo salida 443; ADF con Managed Identity, sin credenciales embebidas.
Landing de datos Azure Storage Account (Blob) Standard GPv2, tier Hot Contenedores separados raw/processed; acceso vía Private Endpoint, sin claves compartidas (RBAC + Managed Identity).
Validación Azure Functions Elastic Premium (evita cold start) Valida XML contra XSD; integrado con Application Insights para trazabilidad de errores.
Orquestación Logic Apps (Standard) Standard, plan dedicado Workflow que coordina Storage → Functions → SQL; dispara alertas ante fallo de cualquier paso.
Calendario regulatorio Azure SQL Database Basic / S0 (bajo volumen) TDE habilitado; acceso vía Private Endpoint; tabla de obligaciones y estados diarios.
Reintentos Durable Functions (misma Function App) Patrón Orchestrator + Retry Backoff exponencial ante fallas transitorias de red o del portal SMV.
Carga al portal Power Automate Desktop (RPA) Licencia por máquina/usuario Ejecuta en VM Windows (Azure VM); credenciales del portal SMV en Azure Key Vault, nunca hardcodeadas.
Evidencia Blob Storage con Immutable Policy (WORM) Lifecycle Hot → Cool → Archive Retención de 365 días; política de inmutabilidad a nivel de contenedor (cumplimiento regulatorio).
Monitoreo Power BI Pro / Premium por usuario Dataset conectado a SQL/Storage; refresco programado o DirectQuery según SLA de actualización.
Alertas Logic Apps + Azure Monitor Action Groups — Conectores nativos a Teams y Outlook/Office 365 ante envíos tarde o fallidos.
Seguridad transversal Azure Key Vault + Managed Identities + Private Endpoints — Todos los secretos (credenciales RPA, connection strings) en Key Vault; identidades administradas en ADF/Functions/Logic Apps; red privada extremo a extremo.
Observabilidad Azure Monitor + Log Analytics + Application Insights — Logs centralizados de todos los componentes; alertas basadas en métricas de fallo/latencia del pipeline diario.
